# Asset Attribution

Every third-party asset must be listed here with its source, author and licence
before it is committed. Keep the licence text alongside the asset when the
licence requires it.

## Current assets

| Asset | Source | Author | Licence |
|---|---|---|---|
| `icon.svg` | Godot Engine project template | Godot contributors | CC BY 4.0 |
| `assets/sprites/terrain/*`, `assets/sprites/buildings/*`, `assets/sprites/ui/*`, `assets/sprites/fx/*` | Created for this project (programmatic painterly SVG and original Blender/Cycles renders) | StrategyGame project | Original work, project-owned |

## Fonts

No third-party font files are bundled yet; the project uses Godot's built-in
default font. When a custom font is added, record the OFL/CC licence here and
commit the licence file next to the `.ttf`/`.otf`.

## Rules

1. Prefer CC0 / public-domain sources.
2. CC BY assets require visible attribution in-game (credits screen) as well as
   this file.
3. Never commit an asset whose licence forbids redistribution with source.
4. Note the exact download URL and date when importing a new pack.
